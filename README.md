# Gestor de Tareas

## Descripción

Sistema desarrollado en Python que permite agregar tareas, listar las tareas registradas y mostrar el progreso de las tareas completadas.

## Integrantes

- Carlos Zambrano — Agregar tareas
- Jhonatan — Listar tareas
- Bryan — Mostrar progreso

## Funcionalidades

- Agregar tareas.
- Listar tareas.
- Mostrar progreso.
- Salir del sistema.

## Tecnologías utilizadas

- Python
- Git
- GitHub

## Ejecución

Clonar el repositorio y ejecutar:

python main.py
